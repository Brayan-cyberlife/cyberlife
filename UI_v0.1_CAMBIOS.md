# CYBER LIFE UI v0.1

Archivos preparados para reemplazar en el repositorio.

## Cambios principales
- Nuevo icono transparente `cyberlife-icon.svg` para el sidebar.
- Nuevo lockup horizontal transparente `cyberlife-lockup.svg` para login y registro.
- Sidebar horizontal, compacto y sin duplicar CYBER LIFE.
- Dashboard reorganizado: KPIs arriba, vencimientos/categorías en dos columnas y valor total separado.
- Alta/edición de activos organizada en secciones 01–04 con grids estables y acciones alineadas.
- Perfil, Ajustes y Suscripción consolidados con tarjetas y espaciado consistente.
- Toolbar de Activos convertida en bloque visual ordenado.
- Responsive para pantallas pequeñas.
